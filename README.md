# Underwater coverage reproducibility

Public reproducibility materials for *Probabilistic Coverage Optimization for Underwater Sensor Networks under Three-Dimensional Localization Uncertainty*.

The verified computational revision, source code, formula-to-code documentation and frozen data are being prepared. Numerical benchmarks are computational experiments; Copernicus Marine currents, when included, are explicitly identified as ocean reanalysis rather than sensor field measurements.

No account credentials or confidential review reports are published here.
